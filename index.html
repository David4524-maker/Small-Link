¿Cómo funciona?

1. Pegas una URL larga (ej: youtube.com/@usuario/videos).
2. Small Link extrae el dominio (youtube.com) y le añade un código aleatorio.
3. El enlace mostrado parece un enlace corto del propio sitio (youtube.com/xK9mP2).
4. Al abrirlo dentro de esta app, redirige a la URL larga original.
Nota: no es un acortador real de servidor — el enlace se resuelve localmente en este navegador.
